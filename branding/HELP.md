# Optimize help

Optimize is your workspace for product knowledge, support drafts, and operations.

## Start a conversation

Choose **Add project** and select the folder for your work. Create a workspace, choose a model, and send your request. Files, drafts, and terminal work use the selected workspace. The Optimize emblem animates while the assistant is working.

## Choose a model

Open the model control under the message box. It shows the models connected to this Mac. Profiles save a model and thinking preference for reuse. An administrator configures model access in **Settings → Providers**.

## Use tools

Files and terminal tools work in your workspace. Browser access is controlled in **Settings → Agents → Browser tools**. Enable it only for the workflows that need it. Plugins and extensions add capabilities; install trusted code through your administrator.

Shopify, Gorgias, and company documents are not connected in this review build. The assistant can prepare drafts from files and information you provide. A draft is not a sent customer reply or a completed business action.

## Manage work

**History** reopens previous conversations. **Schedules** manages recurring tasks. Workspace files, terminal tabs, and browser tabs stay together. Use workspace actions to organize or archive completed work.

## Settings and support

**Appearance** controls colors and text size. **About** shows the app version, updates, and licenses. **Help → Run diagnostics** collects troubleshooting information. Review diagnostics before sharing them.

Device pairing is optional and managed under your host settings. Ask your administrator before connecting another device or changing connection settings.
